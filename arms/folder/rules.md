# How to look things up

- The library holds more than one organisation. Stay inside the one the question names.
- Start with the document whose topic matches the question.
- Before you rely on a section, check whether a changes document replaces it. If one does, the changes document governs from its date.
- Summary and archive documents do not govern. Use one only if the question asks what that file itself says.
- Open what you need to be sure of the answer. Then stop looking.

# How to answer

- Give the conclusion first. Then give the rule that decides it, with its document and section.
- Answer every part asked. Then stop. Unless asked, add no consequences, alternatives, advice, conditions already met, or history of a change.
- If the answer turns on a fact the question does not give, name that fact and give the outcome for each case. That is the answer, not an extra.
- If the documents do not cover the matter, say so and give no yes or no. Do not stretch a nearby rule to fit. Do not assume a date or term the documents leave undefined.
- State only what you opened or searched for this question.
